# Time-Series Analysis of Global Temperature Data

This project was completed as part of the IDEAS TIH Summer Internship Program 2026.

## Project Objective
The objective of this project is to analyze global temperature data using time-series analysis techniques and perform basic clustering evaluation using the MNIST digits dataset as required in the assigned notebook.

## Dataset Used
- monthly_csv.csv

## Tools and Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- SciPy
- Jupyter Notebook

## Tasks Completed
- Loaded and inspected the global temperature dataset
- Converted date values into datetime format
- Extracted year and month features
- Calculated 12-month moving average
- Filtered last 20 years of data
- Aggregated temperature data by source, year, and month
- Created pivot table for yearly and monthly temperature analysis
- Loaded MNIST digits dataset
- Applied K-Means clustering
- Evaluated clustering using macro F1 score
